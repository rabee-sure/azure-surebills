Get active products

Use this API to get active products. In the response of this API, you will get active created products.

GET
BASE_URL/api/v1/getActiveProducts
Request Header
Authorizationmandatory
  • Validation Rules
    stirng

    Field is a string that consists of any characters that return from pos login token.
