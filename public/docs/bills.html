Create Sub-Account

Use this API to create the new user add a new application under this channel. In the response of this API, you will get the client_id, secret, webhook_secret.

POST
https://bills.surepay.sa/api/v1/channels/{CHANNEL_ID}/sub-account
Request Parameters
channel_tokenmandatory
  • Validation Rules
    stirng

    Field is a string that consists of any characters.

business_namemandatory

  • business name

    Validation Rules
    stirng

    Field is a string that consists of any characters.

emailmandatory
  • Validation Rules
    stirng

    Field is a string must be email

namemandatory
  • Validation Rules
    stirng

    Field is a string that consists of any characters.

mobilemandatory
  • Validation Rules
    stirng

    Field is a string must be SA mobile

mada_fixedmandatory
  • Validation Rules
    decimal
mada_percentagemandatory
  • Validation Rules
    decimal
credit_cards_fixedmandatory
  • Validation Rules
    decimal
credit_cards_percentagemandatory
  • Validation Rules
    decimal
redirectmandatory
  • Validation Rules
    stirng

    Field is a string must be URL

webhook_urlmandatory
  • Validation Rules
    stirng

    Field is a string must be URL
